# Personal Portfolio

Personal portfolio website of **Jaire Rafael Reyes Cortez**, an aspiring graphic designer and BSIT student at La Consolacion University Philippines.

Built as the Final Project for **IT ELEC 4 – Web Systems and Technologies 2**.

## Sections

- **Home** – name, introduction and tagline
- **About Me** – personal introduction and educational background
- **Skills** – Java, Python, C#, MySQL, HTML & CSS, JavaScript
- **Projects** – Simple Calculator, Student Hub, FinTrack Financial Tracker
- **Achievements** – certifications and rankings, with certificate images
- **Contact Me** – email, phone and Facebook

## Built With

- HTML5
- CSS3 (responsive layout, no frameworks)
- JavaScript (mobile menu, scroll animations, active nav highlight)
- Inter font from Google Fonts

